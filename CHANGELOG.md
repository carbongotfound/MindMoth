# Changelog

## 1.1.0 Public Beta

- Replaced leftover brain images in the toolbar, icons, dashboard and blocker with the approved moth art.
- Rebuilt banner composition with the mascot on the left and text/buttons in a separate clear area.
- Added a stable, compact popup and the supplied PNG service logos.
- Fixed View all navigation with a dedicated Challenges & milestones page.
- Replaced invented achievement counters with recorded days, completed focus activity and close-instead events.
- Added background-enforced pause/off, early-focus-stop, reset and weakening reviews, plus automatic restoration after a 10-minute pause.
- Serialized model mutations and kept expiry/cooldown state persistent.
- Moved intervention drafts out of website sessionStorage into tab-scoped extension storage.
- Added real Node logic tests, Chromium DOM tests using an extension-API adapter, and release/resource checks.
- Added the illustrated static website, install/contribution/privacy guides and optional GitHub Pages workflow.

The earlier 1.0.x design prototypes are superseded. This release remains a public beta pending native Chrome/Opera GX installation testing across additional machines.
